1. RNN · pass information along a chain

Each state combines the current word with the previous state. To reach h₄, information from “The” passes through h₂ and h₃.

2. RNN + attention · read from stored states

The encoder still reads sequentially. The decoder keeps access to every source state, and its previous state supplies a query for the current read. Here the read emphasizes “cat.”

qᵢ is the query at position i; kⱼ and vⱼ are the key and value at position j. dₖ is the key dimension. Each row of weights sums to one.

Each input produces a query, key, and value. Highlighted arrows show the read for “cat”; faint arrows show the other reads. These outputs can be computed together. Full, unmasked attention is shown.
